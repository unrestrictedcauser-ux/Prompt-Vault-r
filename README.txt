Kat's Prompt Vault — Android home-screen web app

Files: index.html, manifest.webmanifest, icon.svg, sw.js

To install:
1. Upload all four files to a HTTPS web host, keeping them in the same directory (GitHub Pages works).
2. Open the hosted URL in Chrome on Android.
3. Chrome menu (three dots) > Install app or Add to Home screen.
4. Save your prompts with + New. Tap Copy to reuse them.

Data stays in the browser's local storage on that device/browser and does not sync across devices. Use Export backup regularly and keep the JSON file safe. Clearing site data or switching browsers may remove access to saved entries. Imported JSON backups merge by ID.

No external scripts, analytics, accounts, or network requests are required after initial installation.
